# LUMA AGENCY

Site vitrine premium pour LUMA AGENCY, agence de communication basée à Dakar.

## Structure

- `index.html` : page d’accueil
- `css/style.css` : styles et variables de design
- `js/script.js` : interactions et animations
- `assets/logo/` : logo et éléments visuels
- `assets/images/` : espace prévu pour les images supplémentaires
- `assets/icons/` : espace prévu pour les icônes

## Personnalisation

Les couleurs, textes, coordonnées, réseaux sociaux et projets sont facilement modifiables dans le fichier `index.html` et les variables CSS dans `css/style.css`.

## Démarrage local

```bash
cd /workspaces/luma_agency
python3 -m http.server 8000
```

Puis ouvrez : http://localhost:8000

## Compatibilité GitHub Pages

Le site est prêt pour GitHub Pages, sans dépendances Node ou build.
